# Ink Reveal — svg animation on scroll

Інтерактивна лабораторія ефекту «чорнильного» проявлення зображення по скролу:
SVG-маска, край якої рве `feTurbulence` + `feDisplacementMap`, і GSAP ScrollTrigger як драйвер.

## Що вміє

- **Свої зображення.** Два шари — базовий (видно до проявлення) і шар проявлення
  (виїжджає з-під маски). Drag & drop або клік по слоту; можна кинути файл прямо на кадр.
  Формати: png, jpg, webp, avif, svg. Ліміт 12 МБ.
- **Режими базового шару:** своє зображення · те саме, що й зверху · порожньо.
- **Автоматичні пропорції.** Ширина в'юбоксу завжди 1000 u, висота рахується з
  пропорцій завантаженої картинки — тому значення фільтра лишаються порівнюваними
  між різними зображеннями.
- **Пресети:** Heron ink, Рваний папір, Дим, Бризки.
- **Живий код.** Панель унизу віддає готовий HTML + JS + CSS під поточні значення.

## Локальний запуск

Це один статичний файл — ніякого білду.

```bash
python3 -m http.server 4180
```

Далі http://localhost:4180

## Структура

- `index.html` — увесь інструмент, зображення за замовчуванням вшиті як data-URI
- `samples/architecture.avif` — приклад для кнопки «Зразок avif»
